PROVENLY — LOGO KIT
===================

Brand colors
  Navy / ink  #0F1B2D
  Verify green #0E9F6E   (the "ly" in the wordmark)
  Seal gold    #C79A3A
Wordmark font: Hanken Grotesk, weight 800 (already converted to vector
outlines in the SVGs, so no font file is needed — they render correctly
everywhere, including as an <img>).

FILES
  provenly-logo.svg          Horizontal lockup, dark text — for light backgrounds
  provenly-logo-light.svg    Horizontal lockup, white text — for dark backgrounds
  provenly-logo.png          Raster lockup, dark text (transparent)
  provenly-logo-light.png    Raster lockup, white text (transparent)
  provenly-mark.svg          Seal mark only (pure vector, scales infinitely)
  provenly-mark-512.png      Seal mark, 512px (transparent)

  FAVICON / APP ICONS
  favicon.ico                Multi-resolution (16/32/48) — drop in site root
  favicon.svg                Scalable favicon (modern browsers)
  favicon-16.png             16x16
  favicon-32.png             32x32
  favicon-48.png             48x48
  apple-touch-icon.png       180x180, navy background (iOS home screen)
  maskable-512.png           512x512, navy background w/ safe area (Android PWA)

  preview.html               Visual contact sheet of the whole kit
